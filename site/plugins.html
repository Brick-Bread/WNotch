Plugins

Plugins add activities to the pill, cards and pages to the notch, and whole themes. Press Install and Notch opens, tells you what the plugin is, and installs it only if you say yes.

Only install plugins you trust. A plugin is a program that runs as you, with the same access to your files and accounts. The permissions shown here are what the author says the plugin uses; they are a statement, not a limit.

Make your own

A plugin is a small .NET library with a plugin.json, published as one .zip on a GitHub release. To be listed here, open a pull request that adds it to site/plugins/registry.json.
